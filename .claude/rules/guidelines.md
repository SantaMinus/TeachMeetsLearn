# Code style

1. Never add imports using asterisk – "*".
2. When writing Spock tests, specify the stub agrument type when possible (e.g., "_ as Account").
3. When writing code / tests, make sure the lines are no longer than 120 chars where possible. Wrap
   meaningfully.
4. Use code formatting on the written code (Cmd + Option + L).
5. Use Google code style.
